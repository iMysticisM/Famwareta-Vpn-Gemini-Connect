# 🛡️ FamVpnGemini — سرویس اختصاصی Egress مسکونی، استخر هوشمند و داشبورد ضد DPI

پروژه **FamVpnGemini** یک راهکار مهندسی‌شده، کاملاً مستقل و اختصاصی برای حذف قطعی مشکل شناسایی دیتاسنتر (Datacenter IP Detection) و نشت آی‌پی در سرورهای خارج (مانند انگلستان) است. 

این نرم‌افزار بدون اینکه کوچک‌ترین نام یا اثری از سرویس‌های واسط داشته باشد، ترافیک خروجی پنل‌های اینترنت آزاد (مانند هیدیفای، مرزبان، 3X-UI و...) را از طریق **یک استخر هوشمند چند‌اکانتی (Multi-Account Pool Manager)** با پروتکل امن HTTP/2 و IPهای تمیز Fastly عبور می‌دهد.

---

## 🌟 ویژگی‌های برجسته FamVpnGemini

1. **هویت بصری ۱۰۰٪ مستقل و اختصاصی:**
   - رابط وب داشبورد مدرن، شکیل و بهینه‌سازی‌شده تحت برند **FamVpnGemini Console**.
   - کاربر نهایی یا اسکنرها هیچ‌گونه سرنخی از سرویس‌های زیرساختی دریافت نمی‌کنند.

2. **داشبورد وب تحت HTTPS با امکانات کامل:**
   - **Overview:** وضعیت زنده تونل‌ها، پینگ و ترافیک لحظه‌ای مصرف‌شده.
   - **Servers:** مشاهده لیست سرورها، پینگ واقعی (Real Delay Test) و انتخاب کشور خروجی.
   - **Multi-Pool Accounts:** مدیریت استخر اکانت‌ها، نمایش درصد مصرف هر اکانت و سوئیچ خودکار در ۹۵٪ بدون قطعی.
   - **Live Logs:** مشاهده لاگ‌های زنده اتصال و عیب‌یابی.
   - **Settings:** امکان تغییر تمامی متغیرها (پورت‌ها، ترنسپورت، فایروال و...) مستقیماً از وب.

3. **حفاظت سه‌گانه ضد نشت IP و ضد DPI (Anti-Leak & Anti-DPI):**
   - **بدون پورت باز عمومی:** هسته نرم‌افزار فقط روی لوکال‌هاست (`127.0.0.1`) فعال است؛ بنابراین هیچ پورت مشکوکی روی سرور توسط اسکنرهای فیلترینگ شناسایی نمی‌شود.
   - **دسترسی از طریق دامنه فیک و Cloudflare CDN:** داشبورد روی یک مسیر مخفی و رندوم (مانند `https://fake-domain.com/fam-8a7f1b/`) قرار می‌گیرد؛ اسکنرها روی روت فقط خطای ۴۰۴ دریافت می‌کنند.
   - **تونل SSH (امنیت ۱۰۰٪ در سطح نظامی):** قابلیت باز کردن مستقیم پنل از طریق `ssh -L` بدون هیچ‌گونه ترافیک وب روی بستر اینترنت.

4. **سازگاری جامع با تمام پنل‌های اینترنت آزاد (Universal Compatibility):**
   - سازگار با **Hiddify Manager 14**
   - سازگار با **Marzban (مرزبان)**
   - سازگار با **3X-UI / X-UI**
   - سازگار با هسته‌های مستقیم Sing-box و Xray

5. **سیستم به‌روزرسانی درجا (In-Place Auto-Updater):**
   - قابلیت ارتقا و فیکس باگ‌ها بدون حذف اکانت‌ها، تنظیمات و اطلاعات حجم کاربران با دستور `fam-vpn update`.
   - امکان تعویض و افزودن لوگو و تم‌های جدید در آینده.

## 🚀 دستور نصب و پیکربندی سریع یک‌خطی (One-Line Installer)

برای نصب خودکار روی سرور اوبونتو ۲۴.۰۴ یا دبیان، کافیست دستور زیر را با SSH در ترمینال سرور اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/.../server/install.sh | sudo bash
```
*(یا می‌توانید محتویات فایل [`server/install.sh`](server/install.sh) را مستقیماً روی سرور اجرا کنید).*

این اسکریپت تمام مراحل شامل نصب هسته، راه‌اندازی سرویس `systemd`، تنظیم فایروال، تولید پسورد و مسیر رندوم داشبورد را در چند ثانیه انجام می‌دهد.

## 🖥️ دستورات خط فرمان مدیریت اختصاصی (`fam-vpn`)

پس از نصب، ابزار مدیریت سراسری در سرور فعال است:

| دستور | عملکرد |
| :--- | :--- |
| `fam-vpn add` | افزودن تعاملی اکانت جدید به استخر (ایمیل، رمز، کد تایید) |
| `fam-vpn list` | نمایش لیست اکانت‌های استخر، سهمیه ۵۰ گیگی و حجم مصرفی |
| `fam-vpn test` | تست فوری سلامت خروجی و بررسی آی‌پی تمیز Fastly |
| `fam-vpn panel` | نمایش آدرس مخفی داشبورد، نام کاربری و رمز عبور |
| `fam-vpn update` | آپدیت هسته و دارایی‌های وب به آخرین نسخه بدون حذف داده‌ها |
| `fam-vpn status` | مشاهده وضعیت سرویس و پورت‌های محلی |
| `fam-vpn logs` | مانیتورینگ زنده لاگ‌ها و اتصالات |

## 🔒 راهنمای اتصال ایمن به داشبورد (جلوگیری از فیلتر و نشت IP)

### روش ۱ (ساده‌ترین و امن‌ترین - بدون باز کردن پورت):
روی لپ‌تاپ یا کامپیوتر خود در ترمینال یا PowerShell این دستور را بزنید:
```bash
ssh -L 10820:127.0.0.1:10820 root@YOUR_SERVER_IP
```
سپس مرورگر خود را باز کرده و آدرس زیر را وارد کنید:
`http://127.0.0.1:10820/app/`
این اتصال ۱۰۰٪ از داخل تونل رمزنگاری‌شده SSH رد می‌شود و هیچ اسکنری در اینترنت متوجه وجود داشبورد نمی‌شود.

### روش ۲ (اتصال وب با HTTPS و دامنه فیک پشت کلادفلر):
کد کانفیگ موجود در [`server/nginx-reverse-proxy.conf`](server/nginx-reverse-proxy.conf) را در بلاک Nginx دامنه فیک خود قرار دهید. سپس داشبورد با مسیر مخفی باز می‌شود:
`https://your-fake-domain.com/fam-XXXXXX/`
