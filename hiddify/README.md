# راهنمای اتصال هیدیفای منیجر ۱۴ به استخر FamVpnGemini

این راهنما ساده‌ترین روش را برای اضافه کردن خروجی استخر FamVpnGemini به پنل هیدیفای ۱۴ توضیح می‌دهد.

---

## روش سریع و بدون پیچیدگی (فقط یک کانفیگ اختصاصی)

برای اینکه فقط یک کانفیگ (مثلاً `🇬🇧 IP4 اختصاصی Clean IP`) ترافیکش از استخر FamVpnGemini رد شود و سایر کانفیگ‌ها دست‌نخورده بمانند:

### گام اول: اضافه کردن اوت‌باند SOCKS5 در هیدیفای
1. وارد پنل هیدیفای شوید.
2. از منوی کناری به مسیر **تنظیمات (Settings) ← ویرایشگر پروکسی (Proxy Editor) ← قالب‌ها (Templates)** بروید.
3. در لیست قالب‌ها، قالب زیر را پیدا کنید:
   - اگر هسته شما Sing-box است: `hiddify-core/server/base/outbounds`
   - اگر هسته شما Xray است: `xray/server/base/outbounds`
4. روی دکمه **محتوای سفارشی (Override)** کلیک کنید تا قابل ویرایش شود.
5. قطعه کد زیر را به لیست اوت‌باندها اضافه نمایید:

```json
{
  "tag": "famvpn-pool",
  "type": "socks",
  "server": "127.0.0.1",
  "server_port": 10810,
  "version": "5"
}
```
*(اگر هسته Xray است، پروتکل به صورت `"protocol": "socks"` با ساختار سرور Xray نوشته می‌شود).*
6. دکمه **ذخیره** را بزنید.

---

### گام دوم: روتینگ کانفیگ یا کاربر
برای اینکه مشخص کنید چه ترافیکی از این خروجی رد شود، ۲ راه بسیار ساده دارید:

#### راهکار الف (به ازای هر کاربر - ساده‌ترین روش):
1. از منوی هیدیفای به **مدیریت کاربران** بروید.
2. کاربر مورد نظر (یا کاربری که اشتراک VIP خریده است) را ویرایش کنید.
3. در بخش **Extra Params** (پارامترهای اضافی) این را بنویسید:
   ```json
   {
     "outbound": "famvpn-pool"
   }
   ```
4. در قالب روتینگ (`hiddify-core/server/base/route`)، این قانون را قرار دهید:
   ```jinja
   {% for u in ctx.users if u.extra.outbound == 'famvpn-pool' %}
   {
     "auth_user": ["{{ u.uuid }}"],
     "outbound": "famvpn-pool"
   },
   {% endfor %}
   ```
5. از صفحه **اقدامات (Actions)**، گزینه **اعمال تنظیمات (Apply Configs)** را بزنید.
اکنون تمام ترافیک این کاربر به صورت خودکار از IP تمیز و مسکونی FamVpnGemini عبور می‌کند!

#### راهکار ب (روتینگ بر اساس دامنه‌های حساس - هوشمند):
اگر می‌خواهید برای همه کاربران، فقط سایت‌های هوش مصنوعی (ChatGPT)، بانک‌ها و صرافی‌ها از FamVpnGemini رد شوند تا سهمیه استخر هدر نرود:
در قالب `hiddify-core/server/base/route` این رول را اضافه کنید:
```json
{
  "domain_suffix": [
    "openai.com",
    "chatgpt.com",
    "claude.ai",
    "paypal.com",
    "stripe.com"
  ],
  "outbound": "famvpn-pool"
}
```

---

## راه‌اندازی و تست
پس از اعمال تنظیمات:
1. در گوشی یا سیستم خود به کانفیگ وصل شوید.
2. سایت `https://ipinfo.io` یا `https://browserleaks.com/ip` را باز کنید.
3. آی‌پی خروجی باید متعلق به **Fastly Egress** باشد و هیچ ردی از آی‌پی سرور دیتاسنتری شما وجود نخواهد داشت.
